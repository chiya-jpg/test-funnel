# Images

The Clinical Leadership page currently renders branded SVG placeholders:

- `eli-inzlicht.svg` — Dr. Eli Inzlicht-Sprei, MD
- `raymond-sultan.svg` — Raymond R. Sultan, DPA, FAAPA

When you have real portraits, drop them in as `eli-inzlicht.png` and
`raymond-sultan.png`, then update the two `<img src>` paths in
`clinical-leadership.html` to point at `.png` instead of `.svg`.

Recommended specs for the real photos:
- Portrait aspect ratio (~3:4), 1200 × 1600 px
- Neutral background, professional lighting
- Under 400 KB each (compress with TinyPNG or similar)
